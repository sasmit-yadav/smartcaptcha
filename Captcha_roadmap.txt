PHASE 2 — BUILD TELEMETRY SDK
================================================================================

GOAL: A lightweight JavaScript file that silently collects behavioral signals
      from any browser page it is loaded on.

[ ] 2.1 — CREATE SDK STRUCTURE (/sdk)
    [ ] Initialize: npm init
    [ ] Create src/index.js (main entry point)
    [ ] Create src/collectors/ folder:

    [ ] Create src/core/ folder:
        - session.js    ← session ID management
        - buffer.js     ← event batching
        - transport.js  ← API communication
        - config.js     ← SDK configuration
    [ ] Create src/utils/ folder:
        - throttle.js
        - timestamp.js
        - sanitize.js   ← ensure no PII is captured

[ ] 2.2 — IMPLEMENT SESSION MANAGER (src/core/session.js)
    [ ] Generate session ID: crypto.randomUUID()
    [ ] Store in sessionStorage (cleared on tab close)
    [ ] Expose getSessionId() function
    [ ] Track session start timestamp
    [ ] Detect tab visibility changes (Page Visibility API)
    [ ] Track if session is on mobile or desktop
    [ ] Expose getSessionMeta() returning:
        {
          sessionId,
          startTime,
          userAgent,
          platform,
          screenWidth,
          screenHeight,
          deviceType (mobile/desktop)
        }

[ ] 2.3 — IMPLEMENT MOUSE COLLECTOR (src/collectors/mouse.js)
    [ ] Listen to: document.addEventListener('mousemove', handler)
    [ ] Capture per event:
        { type: 'mm', x: e.clientX, y: e.clientY, t: Date.now() }
    [ ] Apply 50ms throttle (DO NOT capture every pixel move)
        - Use requestAnimationFrame OR manual lastCapture timestamp check
        - if (now - lastCapture < 50) return;
    [ ] Track total distance traveled (cumulative sum of movements)
    [ ] Detect if movement is suspiciously linear:
        - Compute angle between consecutive points
        - Store angle change per segment
    [ ] Export startMouseTracking() and stopMouseTracking()

[ ] 2.4 — IMPLEMENT CLICK COLLECTOR (src/collectors/click.js)
    [ ] Listen to: document.addEventListener('click', handler)
    [ ] Capture:
        { type: 'cl', x: e.clientX, y: e.clientY, t: Date.now(), target: e.target.tagName }
    [ ] Track inter-click timing:
        - Store last click timestamp
        - On each click: interval = now - lastClick
        - Store interval alongside event
    [ ] Detect double clicks (interval < 300ms)
    [ ] DO NOT capture: href, form values, passwords, text content of elements
    [ ] Export startClickTracking()

[ ] 2.5 — IMPLEMENT KEYBOARD COLLECTOR (src/collectors/keyboard.js)
    [ ] Listen to: keydown, keyup events
    [ ] NEVER capture e.key or e.code for printable characters
        - Only safe keys: Backspace, Tab, Enter, ArrowKeys
        - For all other keys: record as "CHAR" (anonymized)
    [ ] Capture per keydown:
        { type: 'kd', k: safeKey, t: Date.now() }
    [ ] Capture per keyup:
        { type: 'ku', k: safeKey, t: Date.now() }
    [ ] Compute hold duration per key: keyup.t - keydown.t
    [ ] Compute inter-key interval: keydown.t - previousKeyup.t
    [ ] Track backspace frequency (correction behavior)
    [ ] Export startKeyboardTracking()

[ ] 2.6 — IMPLEMENT SCROLL COLLECTOR (src/collectors/scroll.js)
    [ ] Listen to: document.addEventListener('scroll', handler)
    [ ] Apply 100ms throttle (scroll events fire extremely rapidly)
    [ ] Capture:
        { type: 'sc', y: window.scrollY, t: Date.now() }
    [ ] Compute scroll velocity: delta_y / delta_t
    [ ] Detect scroll direction changes (reversals = very human behavior)
    [ ] Detect scroll pauses (no scroll event for > 500ms)
    [ ] Track max scroll depth reached in session
    [ ] Export startScrollTracking()

[ ] 2.7 — IMPLEMENT FOCUS COLLECTOR (src/collectors/focus.js)
    [ ] Listen to:
        - window blur / focus events (tab switching)
        - document visibilitychange event
    [ ] Capture:
        { type: 'fv', state: 'blur'|'focus', t: Date.now() }
    [ ] Track total time page was focused vs unfocused
    [ ] Track number of focus switches in session
    [ ] Behavioral insight: humans frequently switch tabs; bots usually don't

[ ] 2.8 — IMPLEMENT TOUCH COLLECTOR (src/collectors/touch.js)
    [ ] Listen to: touchstart, touchmove, touchend
    [ ] Capture:
        { type: 'tc', x: touch.clientX, y: touch.clientY, t: Date.now() }
    [ ] Apply throttle (similar to mousemove)
    [ ] Track touch pressure if available (e.touches[0].force)
    [ ] Differentiate tap vs swipe vs long-press

[ ] 2.9 — IMPLEMENT EVENT BUFFER (src/core/buffer.js)
    [ ] Create in-memory array: events = []
    [ ] push(event) method: adds event to array
    [ ] flush() method: returns current events array, clears buffer
    [ ] Auto-flush triggers:
        - Every 5 seconds (setInterval)
        - When buffer reaches 100 events
        - On page unload (beforeunload event)
    [ ] On flush: call transport.send(events)
    [ ] Handle flush failures: retry with exponential backoff (max 3 retries)

[ ] 2.10 — IMPLEMENT TRANSPORT LAYER (src/core/transport.js)
    [ ] send(events) method:
        - Build payload:
          {
            sessionId: session.getSessionId(),
            meta: session.getSessionMeta(),
            events: events,
            timestamp: Date.now()
          }
        - POST to /api/telemetry
        - Include API key in header: X-API-Key: <key>
        - Use fetch() with keepalive: true (survives page close)
    [ ] On 429 (rate limit): back off and retry
    [ ] On 5xx: retry up to 3 times
    [ ] On 4xx: log error, do not retry
    [ ] Session start: POST /api/session/start on SDK init
    [ ] Session end: POST /api/session/end on page unload

[ ] 2.11 — IMPLEMENT SDK INIT (src/index.js)
    [ ] Export SmartCaptcha object with init() method:
        SmartCaptcha.init({
          apiKey: "your-key",
          endpoint: "https://api.smartcaptcha.ai",
          debug: false
        })
    [ ] init() should:
        - Validate apiKey is provided
        - Initialize session
        - Start all collectors
        - Start buffer auto-flush
        - Register page unload handler
        - Log "SmartCaptcha initialized" if debug: true

[ ] 2.12 — BUILD SDK BUNDLE
    [ ] Set up esbuild or Rollup for bundling
    [ ] Target: ES2017+ (no IE support needed)

    [ ] Create Supabase project (free tier)
    [x] Create tables via SQL (with full ML feature columns):

        CREATE TABLE projects (
          id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
          owner_id UUID NOT NULL,
          name VARCHAR(100) NOT NULL,
          allowed_domains TEXT[],
          created_at TIMESTAMP DEFAULT NOW()
        );

        CREATE TABLE api_keys (
          id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
          project_id UUID REFERENCES projects(id),

        );

        CREATE TABLE sessions (

          device_type VARCHAR(20),

          created_at TIMESTAMP DEFAULT NOW()
        );

        CREATE TABLE events (
          id BIGSERIAL PRIMARY KEY,
          session_id VARCHAR(36) REFERENCES sessions(id),
          event_type VARCHAR(10) NOT NULL,
          t BIGINT,
          x INTEGER,
          y INTEGER,
          dist REAL,
          ang REAL,
          vel REAL,
          total_dist REAL,
          target TEXT,
          click_interval INTEGER,
          is_double BOOLEAN,
          tw INTEGER,
          th INTEGER,
          k TEXT,
          iki INTEGER,
          hold INTEGER,
          scroll_y INTEGER,
          scroll_vel REAL,
          scroll_rev BOOLEAN,
          scroll_pause BOOLEAN,
          state TEXT,
          action TEXT,
          force REAL,
          duration INTEGER,
          gesture TEXT,
          swipe_dist REAL,
          swipe_vel REAL,
          payload JSONB NOT NULL,
          received_at TIMESTAMP DEFAULT NOW()
        );

        -- Index for performance
        CREATE INDEX idx_events_session ON events(session_id);
        CREATE INDEX idx_events_type ON events(event_type);
        CREATE INDEX idx_events_received ON events(received_at);
        CREATE INDEX idx_sessions_created ON sessions(created_at);
        CREATE INDEX idx_sessions_label ON sessions(label);
        CREATE INDEX idx_sessions_project ON sessions(project_id);

PHASE 6 — FEATURE ENGINEERING ENGINE
================================================================================

GOAL: Convert raw event arrays into meaningful numerical features per session.
      This is the most technically important phase.

[ ] 6.1 — SET UP FEATURE ENGINEERING MODULE (/ml/features/)
    [ ] Create files:
        - mouse_features.py
        - keyboard_features.py
        - scroll_features.py
        - click_features.py
        - session_features.py
        - feature_pipeline.py  ← orchestrates all extractors
        - feature_store.py     ← saves features to DB/CSV

[ ] 6.2 — MOUSE FEATURES (mouse_features.py)
    Input: list of {x, y, t} events from a session

    [ ] average_velocity
        - Compute distance between consecutive points: sqrt((x2-x1)² + (y2-y1)²)
        - Compute time delta: t2 - t1 (in ms)
        - velocity = distance / time
        - Return: mean of all velocity values

    [ ] velocity_variance
        - Compute all velocities (as above)
        - Return: standard deviation of velocities
        - HIGH variance = human (irregular speed)
        - LOW variance = bot (robot-constant speed)

    [ ] acceleration_variance
        - Compute velocity change between consecutive segments
        - acceleration = (v2 - v1) / (t2 - t1)
        - Return: standard deviation of accelerations

    [ ] path_curvature_mean
        - For each triple of consecutive points (A, B, C):
          compute angle ABC using dot product
        - curvature = deviation from straight line (180° = straight)
        - Return: mean angle deviation
        - LOW curvature mean = very straight paths = bot signal

    [ ] movement_entropy
        - Discretize movement directions into 8 bins (N, NE, E, SE, S, SW, W, NW)
        - Compute frequency of each direction
        - Compute Shannon entropy: -sum(p * log(p))
        - HIGH entropy = human (moves in many directions)
        - LOW entropy = bot (moves in same direction repeatedly)

    [ ] pause_frequency
        - Count gaps in mouse movement > 500ms where no mousemove fired
        - Return: count of pauses / total session duration
        - Humans pause frequently; bots often move continuously

    [ ] total_distance_traveled
        - Sum of all movement distances in pixels

    [ ] micro_jitter_amplitude
        - For very short movements (< 10px), compute variance
        - Humans have natural hand tremor; bots are pixel-perfect

[ ] 6.3 — CLICK FEATURES (click_features.py)
    Input: list of {x, y, t} click events

    [ ] click_count
        - Total number of clicks in session

    [ ] inter_click_interval_mean
        - Time between consecutive clicks (mean)

    [ ] inter_click_interval_variance
        - Standard deviation of inter-click intervals
        - ZERO variance = bot (exact same delay between all clicks)

    [ ] click_position_variance
        - For repeated clicks on same element type:
          measure x,y variance around expected position
        - ZERO variance = bot always clicks exact pixel center

    [ ] double_click_frequency
        - Count clicks with interval < 300ms
        - Normalized by total click count

    [ ] off_target_click_rate
        - Clicks that land slightly outside obvious UI targets
        - Humans sometimes click a few pixels off; bots are exact

[ ] 6.4 — KEYBOARD FEATURES (keyboard_features.py)
    Input: list of {type: 'kd'/'ku', t} keyboard events

    [ ] typing_speed_wpm_estimate
        - Total keystrokes / (session duration / 60000)
        - Very high speed (> 300 wpm) = bot signal

    [ ] inter_key_interval_mean
        - Time between consecutive keydown events (mean ms)

    [ ] inter_key_interval_variance
        - Standard deviation of inter-key intervals
        - Very low variance = bot (types at exact constant speed)

    [ ] key_hold_duration_mean
        - keyup.t - keydown.t for each key (mean)

    [ ] key_hold_duration_variance
        - Standard deviation of hold durations

    [ ] backspace_frequency
        - Count of Backspace key events / total keystrokes
        - Humans make and correct mistakes; bots usually don't

    [ ] typing_pause_count
        - Count gaps > 1000ms between keystrokes (human hesitation)
        - Bots rarely pause mid-typing

    [ ] burst_typing_ratio
        - Percentage of keys typed in bursts (< 50ms between keys)
        - Extremely fast bursts = bot signal

[ ] 6.5 — SCROLL FEATURES (scroll_features.py)
    Input: list of {y, t} scroll events

    [ ] scroll_velocity_mean
        - delta_y / delta_t between consecutive scroll events

    [ ] scroll_velocity_variance
        - Standard deviation of velocities
        - Humans: high variance (fast then slow, then stops)
        - Bots: low variance (scroll at constant speed)

    [ ] scroll_reversal_count
        - Number of times scroll direction changed (up → down or down → up)
        - Humans frequently scroll back up to re-read; bots rarely do

    [ ] max_scroll_depth_fraction
        - Max scrollY / document total height
        - Shows if user read to bottom or just hit submit

    [ ] scroll_pause_count
        - Count scroll pauses > 800ms
        - Humans pause to read; bots scroll continuously

    [ ] scroll_acceleration_signature
        - Humans: scroll with slight ease-in-out (like physics)
        - Bots: constant velocity or exact easing function
        - Feature: skewness of velocity distribution

    [ ] scroll_total_distance
        - Absolute sum of all scroll deltas

[ ] 6.6 — SESSION-LEVEL FEATURES (session_features.py)
    Input: session metadata + all event types

    [ ] session_duration_seconds
        - (ended_at - started_at) in seconds
        - Very short (< 5s) = strong bot signal

    [ ] event_density
        - Total events / session duration
        - Very high density = bot (firing events rapidly)
        - Very low density = abandoned session

    [ ] interaction_diversity_score
        - Count of distinct event types present
        - Normalize: diversity = distinct_types / total_possible_types
        - Humans use mouse + keyboard + scroll + click
        - Bots often only use one or two types

    [ ] mouse_to_click_ratio
        - mouse events / click events
        - Humans move mouse much more than they click
        - Bots may click without moving (or move exactly to target)

    [ ] keyboard_without_mouse_ratio
        - Sessions where keyboard events occur but no mouse movement
        - Could indicate headless browser (no mouse input)

    [ ] focus_switch_count
        - Number of tab blur/focus events
        - Humans multitask; bots don't switch tabs

    [ ] device_type
        - mobile / desktop (binary or one-hot encoded)

    [ ] has_touch_events
        - Boolean: true if touch events present
        - Helps distinguish real mobile users from spoofed agents

[ ] 6.7 — BUILD FEATURE PIPELINE (feature_pipeline.py)
    [ ] Function: extract_features(session_id) → feature_dict
        - Load all raw events from DB for session
        - Group by event type
        - Run each feature extractor
        - Return combined dict of all features
    [ ] Function: batch_extract(session_ids) → DataFrame

        - Return pandas DataFrame (one row per session)
    [ ] Handle edge cases:
        - Session with zero mouse events → fill mouse features with 0

[ ] 9.1 — CREATE ML INFERENCE SERVICE (/backend/ml_service/)
    [ ] Create ml_inference.py:

        - Expose predict(features: dict) → float (risk score 0.0 to 1.0)
        - Input: feature dictionary (same format as training)
        - Output: risk score (probability of being a bot)

    [ ] Implementation:
        import joblib, numpy as np

        model = joblib.load('models/classifier_v1.pkl')
        scaler = joblib.load('models/scaler_v1.pkl')
        feature_order = model_meta['features']

        def predict(feature_dict):
          vector = [feature_dict.get(f, 0) for f in feature_order]
          array = np.array(vector).reshape(1, -1)
          scaled = scaler.transform(array)
          prob = model.predict_proba(scaled)[0][1]  # probability of 'bot'
          return float(prob)

PHASE 12 — SECURITY HARDENING
================================================================================

[ ] 12.1 — REPLAY ATTACK PREVENTION
    [ ] Each telemetry batch must include:
        - nonce: unique random string
        - timestamp: current time (ms)
    [ ] Backend checks:
        - nonce not seen before (store in Redis with 24h TTL)
        - timestamp within ±5 minutes of server time
    [ ] Store used nonces: Redis SET with SETNX + EXPIRE

[ ] 12.2 — REQUEST SIGNING
    [ ] SDK computes HMAC signature of payload:
        signature = HMAC-SHA256(payload_json, client_secret)
    [ ] Backend verifies signature on every request
    [ ] Reject any request with invalid signature

[ ] 12.3 — TELEMETRY COMPRESSION
    [ ] Compress batch payloads with gzip before sending
    [ ] SDK: check if CompressionStream API is available (modern browsers)
    [ ] Fallback: send uncompressed (acceptable for MVP)
    [ ] Reduces bandwidth significantly for high-traffic sites

[ ] 12.4 — SQL INJECTION PREVENTION
    [ ] Always use parameterized queries (never string concatenation)
    [ ] Use SQLAlchemy ORM or parameterized asyncpg queries
    [ ] Validate all UUIDs and strings before DB queries

[ ] 12.5 — XSS PREVENTION IN DASHBOARD
    [ ] Sanitize all session data before rendering in HTML
    [ ] Never use dangerouslySetInnerHTML without sanitization
    [ ] Use Content-Security-Policy headers

[ ] 12.6 — HTTPS EVERYWHERE
    [ ] All services: enforce HTTPS only
